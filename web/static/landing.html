Good to know

A few honest answers.

Do my passwords go to your server?

The new browser vault does not send passwords or vault contents to the server. Your browser encrypts the vault using AES-256-GCM and a key derived from your master password with PBKDF2-SHA256 (600,000 iterations). The encrypted data is saved locally. Like any web tool, you must trust the code delivered by the website and the device you use.

Is this a browser extension or native desktop app?

No. The download is the same tool in one HTML file that opens in your browser. It works offline, but it does not autofill other websites or integrate with your operating system.

How do I move between the website and offline tool?

Download an encrypted backup from your current vault, open the other version, choose Import encrypted backup, and enter your master password. The versions do not automatically sync, so keep track of which copy you update.

What if I forget my password or clear browser data?

A forgotten master password cannot be recovered. Clearing browser data can erase your vault. Keep an encrypted backup outside this browser and remember the master password used for that backup.

I used the previous version. Where is my vault?

The browser vault uses a new format and does not automatically migrate the previous server or Python CLI vaults. Existing data is not deleted. Keep your original installation and backups; do not expect old encrypted exports to import into this browser tool.
